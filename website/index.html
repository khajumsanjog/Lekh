What Lekh does

Designed for quick config tweaks on remote servers and focused coding sessions alike—every feature earns its bytes without bloating the binary.

  • 🧭

    Zero Modes, Instant Muscle Memory

    No getting trapped in command modes. Standard shortcuts (Ctrl+S save, Ctrl+Q quit, Ctrl+Z/Y undo/redo, Ctrl+C/X/V) plus full mouse click, drag selection, and scroll wheel support.

  • 🎨

    5 True-Color Themes & Bracket Glow

    Press Ctrl+T to cycle Default, Dracula, Nord, OneDark, and Gruvbox in 24-bit RGB. Includes subtle current-line highlighting, glowing ()[]{} bracket pairs, and a 1-column minimap scrollbar.

  • 🔍

    Live Smart-Case Search & Replace

    Press Ctrl+F to jump across matches as you type (Enter/↓ next, ↑ previous, F3 repeat) or Ctrl+R to replace all occurrences in a single undoable step.

  • 🔢

    Hybrid Relative Line Numbers

    Press Ctrl+N to cycle between Absolute numbers, Vim-style Relative distance numbers (with exact line number on your cursor row), or distraction-free Off.

  • ⏪

    Group-Merged Undo & OSC 52 Copy

    Consecutive typing and consecutive Backspace/Delete merge naturally into single undo steps. Copying via Ctrl+C also syncs straight to your host clipboard over SSH via OSC 52.

  • 🛡️

    Trojan-Source & Escape Armor

    Hidden bidirectional Unicode overrides (CVE-2021-42574) are exposed as bold red ? markers with an immediate warning. Pasted or file control characters can never inject terminal escape sequences.

How Lekh works under the hood

Lekh is ~4,500 lines of strictly safe Rust (#![forbid(unsafe_code)]) split into five clean, single-purpose modules—no shell-outs, no network calls, and no executed config scripts.

  1. 01 · lib.rs

    0% Idle Event Loop

    Sleeps in the OS kernel on event::read() using zero CPU until a key, mouse, or bracketed paste arrives—then drains queued bursts before drawing once.

  2. 02 · editor.rs

    State & Coordinates

    Validates cursor bounds, word jumps, smart auto-indent, 10k-char bracket matching, and multi-click selection.

  3. 03 · buffer.rs

    Reversible Op Log

    Stores lines as Vec<char> for O(1) column access and records algebraic inverses (Ins↔Del, Split↔Join)—never cloning full snapshots.

  4. 04 · syntax.rs

    Cached Tokenizer

    Single-pass scanner with multi-line state + per-line tok_cache. Editing line k only invalidates cache from line k downward.

  5. 05 · ui.rs

    Single-Flush Frame

    Queues only visible viewport rows into a 64 KB BufWriter and flushes once per frame—zero terminal flicker.

🔒 4-Step Crash-Proof Atomic Save (fileio.rs)

  1. Private O_EXCL Temp File: Writes to .filename.lekh-pid-nanos.tmp with mode 0600 so planted symlinks are refused and secrets are never briefly world-readable.
  2. Symlink & Metadata Preservation: Resolves symlinks so saving updates the real target without breaking your symlink, copying original permissions and preserving BOM + LF/CRLF line endings.
  3. Hardware fsync(): Calls sync_all() on both the temp file and parent directory so bytes hit physical storage.
  4. Atomic POSIX rename(): Swaps the directory entry in one atomic kernel operation—power loss can never leave a truncated 0-byte file.

🛡️ Hostile-Input & Modification Guards

  1. Refuses Traps: Blocks directories, FIFOs, and device nodes (running lk /dev/zero exits cleanly instead of hanging or eating RAM).
  2. Binary & Size Protection: Refuses non-UTF-8 or NUL-byte binaries so executables are never silently mangled, with a configurable 64 MB cap (LEKH_MAX_MB).
  3. Disk-Change Detection: Checks file mtime before saving—if another process modified the file after you opened it, Lekh asks before overwriting.
  4. Panic-Safe Terminal Restore: A RAII TermGuard + custom panic hook guarantees raw mode and alternate screen are always cleaned up.

Download & install

The fastest way to get started is downloading a precompiled release binary directly from GitHub Releases—or building with Cargo in one command.

📦 Official Prebuilt Binaries on GitHub Releases

Every tagged release includes ready-to-run binaries (both lk and lekh) so you can download, extract, and run immediately without installing Rust.

⬇ Open Latest Release All Releases ↗

Run on macOS (Apple Silicon & Intel)

1. Download lekh-macos-arm64.tar.gz from GitHub Releases, extract it, and move lk & lekh into your PATH:

# Extract the downloaded release archive & install:
tar -xzf lekh-macos-arm64.tar.gz
xattr -d com.apple.quarantine lk lekh 2>/dev/null || true
chmod +x lk lekh
sudo mv lk lekh /usr/local/bin/

# Verify & open any file:
lk --version
lk hello.rs

macOS Terminal tip: Enable Use Option as Meta key in Terminal → Settings → Profiles → Keyboard so Option+←/→ jumps by word.

Run on Linux (x86_64 & ARM64)

1. Download the Linux tarball from GitHub Releases, extract it, and install to /usr/local/bin:

# Extract the downloaded release archive & install:
tar -xzf lekh-linux-x86_64.tar.gz
sudo install -m 755 lk lekh /usr/local/bin/

# Start editing:
lk /etc/hosts

Run on Windows (Windows Terminal / PowerShell)

1. Download the Windows .zip archive from GitHub Releases, unzip lk.exe and lekh.exe, and run inside Windows Terminal:

# In PowerShell inside the extracted folder:
.\lk.exe notes.md

# Optional: copy into your user bin folder on PATH:
New-Item -ItemType Directory -Force "$HOME\.local\bin" | Out-Null
Copy-Item .\lk.exe, .\lekh.exe "$HOME\.local\bin\"

Compile & Install from GitHub Source (Rust 1.74+)

Installing from source compiles an LTO-optimized, stripped binary and places both lekh and the short alias lk onto your ~/.cargo/bin PATH:

git clone https://github.com/khajumsanjog/Lekh.git
cd Lekh
cargo install --path .

# Ready anywhere:
lk +1 src/main.rs

How to use Lekh

Run lk for speed or lekh for clarity. Press Ctrl+G or F1 inside the editor anytime to pull up the built-in shortcut overlay.

lk index.html

Open an existing file (or start a new file that won’t touch disk until you press Ctrl+S).

lk +120 src/editor.rs

Open directly at line 120—ideal when jumping to compiler errors or stack traces.

LEKH_MAX_MB=256 lk app.log

Raise the safety file-size guard (default 64 MB) when inspecting huge log files.

How do I publish binaries to GitHub Releases so users can download them?

Build with cargo build --release, package target/release/lk and target/release/lekh into a .tar.gz or .zip, then run gh release create v0.1.0 lekh-macos-arm64.tar.gz --title "Lekh v0.1.0" --generate-notes (or upload them on your repository’s Releases page). Every “Download Latest Release” button on this page automatically points to your newest published release!

How do I paste text from my browser or another app into Lekh?

Use your terminal’s standard system paste shortcut (Cmd+V on macOS, Ctrl+Shift+V on Linux/Windows Terminal). Lekh supports bracketed paste—meaning pasted code won’t trigger runaway auto-indentation, and dangerous control bytes are stripped automatically.

Why are there two commands: lekh and lk?

Both binaries are built from the exact same codebase: lekh is the expressive full name, and lk saves keystrokes when you’re opening dozens of files a day in the terminal.
